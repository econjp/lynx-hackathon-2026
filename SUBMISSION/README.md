# SUBMISSION

**Final model: 50% BOMBASTRAT + 50% GOAT, in one portfolio.**

| file | what |
|---|---|
| `model.py` | the whole model, self-contained (numpy, pandas, polars). `final_positions(prices, macro)` |
| `check.py` | leak test (both methods from Lynx's instructions) and Lynx key figures |
| `positions_insample.csv` | positions for the in-sample period, Lynx format (AsOfDate + one column per asset) |
| `positions.csv` | **the file to hand in**: created by the command below once the out-of-sample data is released |

## What Lynx asks for (from `lynx_materials/lynx-hackathon-instructions.pdf`)
1. "run your strategy on the full data set and save the resulting positions to a csv file which we can evaluate" -> `positions.csv`
2. "You will be required to apply a suitable test" for forward-looking bias -> `check.py`
3. "explain your strategy, how you arrived at it and the code that implements it" -> this page and `model.py`

## When the out-of-sample data arrives
```bash
python SUBMISSION/model.py --prices data/close_prices_insample.csv <out_of_sample_prices.csv> \
                           --macro  data/macro_data_insample.csv  <out_of_sample_macro.csv> \
                           --out    SUBMISSION/positions.csv
python SUBMISSION/check.py SUBMISSION/positions.csv
```
Give the in-sample file first, then the new file: the history warms the signals up. If the new file already
contains the full history, pass only that file. Price files with Open/High/Low/Close columns work too.
Do not change anything in `model.py` after seeing the new data.

## The model in one minute
**BOMBASTRAT** (no market bet) adds three forecasts with equal risk each:
- **Trend**, all 27 assets: slow price trends continue.
- **Inflation**, bonds and stocks: when CPI runs hotter than its own three-year normal, short them.
- **Twins**, commodity pairs that move together: when the gap between them is wide, bet on it closing.

**GOAT** (long tilt in stocks and bonds):
- **Engine 1**: EMA 10/100 long-only on the 10 stocks and bonds, with a trailing stop that arms when the trend is stretched.
- **Engine 2**: 12-month momentum ranked inside each asset class.

Both books are scaled to the same constant risk and averaged 50/50. Positions are sized by 1/volatility,
the book runs at constant risk, and trading is smoothed.

**Why 50/50.** The two are different bets (P&L correlation 0.36). BOMBASTRAT is strong when trends and
inflation moves are large; GOAT is steady because it holds stocks and bonds. Any weight from 33% to 67% scores
about the same, so the weight is not tuned. The mix has a deliberate long tilt of about 0.3.
