Dear team,

The Lynx Hackathon 2026 is approaching! We are looking forward to welcoming you to our office.

The purpose of the event is to give you an introduction to the world of systematic trading in financial markets. Since some but not all of the participants already have some prior knowledge, we have put together some preparation material. Attached to this email you will find a pdf document with detailed instructions and a zip archive with code examples. The instruction document also introduces important technical concepts and we recommend that you read it before the event. The code examples are written in Python and consist of the following files:

• Quickstart.ipynb: A minimal example of running and evaluating a trading strategy.

• Modeling_example.ipynb: A more detailed notebook which explains technical details and the motivation for a simple trading strategy.

• Evaluation.py: An evaluation library which you can use to analyze your trading strategy.

• Example_prices.csv: A synthetic data set to run the example code on. You will receive real data at the event.

You should be able to run the code examples in most Python environments.

General Hackathon information:

• You will need to bring your personal laptops to the event.

• The event will start at 9:00 am, a lighter breakfast will be available from 08:45, and the competition ends at around 5:30pm, followed by a dinner and mingle. The dinner and mingle is optional and will continue until 8pm. Lunch, fika, snacks and beverages will be available during the day.

Please confirm that you have received this information. Don't hesitate to contact us if you have any further questions.
